# Линия силы — состояние проекта

Актуально на 26 октября 2026 года.

## Задача

Telegram-бот и Mini App помогают вести силовые тренировки в зале. Пользователь сам задаёт названия тренировок, мышечные группы, упражнения, расписание, число подходов, диапазоны повторений и стартовые веса. В назначенный день бот присылает план с целевыми весами и повторениями. В Mini App пользователь записывает фактические подходы, просматривает историю и графики, а приложение рассчитывает цели следующего занятия.

## Как устроен проект

| Часть | Реализация | Назначение |
| --- | --- | --- |
| Бот | Python, aiogram | Команды `/start` и `/today`, отправка плана и кнопки Mini App |
| API и расчёты | FastAPI, SQLAlchemy | Проверка Telegram `initData`, хранение программы и результатов, прогрессия нагрузок, аналитика |
| Mini App | React, TypeScript, Vite | Сегодняшний план, запись подходов, история, графики, редактор программы |
| Данные | PostgreSQL | Разделение программ и истории по Telegram ID |
| Развёртывание | Docker Compose, Caddy | Локальный просмотр; конфигурация HTTPS для сервера |

## Что уже работает

- Редактор тренировок и упражнений. Для тренировки можно выбрать несколько мышечных групп из списка: Грудь, Спина, Плечи, Руки, Ноги. Группы можно удалять из выбора. День недели и время «Начало тренировки» выбираются в стилизованных меню.
- Цикл «лёгкая → средняя → тяжёлая» ведётся отдельно для каждой тренировки и переключается после завершения занятия. Вес и диапазон повторов каждой фазы настраиваются для упражнения.
- Следующая цель рассчитывается по завершённым занятиям той же фазы: повышение веса после достижения верхней границы во всех подходах, рост целевых повторов внутри диапазона и снижение веса после двух подряд недовыполнений. Цель можно исправить вручную до выполнения подходов.
- Незавершённая тренировка и результаты отдельных подходов сохраняются. Пропущенное упражнение не участвует в расчёте. История хранит снимок целей на момент занятия.
- Экран прогресса показывает вес, повторы, объём и ориентировочную оценку силы; есть фильтры по мышечной группе, упражнению и типу дня. У смешанной тренировки упражнения доступны в каждой выбранной группе.
- Бот формирует план в назначенный день и учитывает часовой пояс пользователя. Проверяются подпись и срок действия `initData`, секрет webhook и принадлежность данных пользователю.
- Есть локальный режим просмотра без Telegram и режим проверки через отдельного тестового бота с временным HTTPS-туннелем. Основные команды описаны в [README.md](README.md).

## Текущее положение

- Проект работает локально через Docker Compose; просмотр доступен на `http://localhost:8080` после запуска `./scripts/local.ps1 preview` в PowerShell.
- Фронтенд собирается командой `pnpm run build`. Серверный набор содержит 7 тестов для авторизации, прогрессии, сохранения черновика, разделения пользователей, смешанных групп и однократной отправки плана за день; последний локальный прогон завершился успешно.
- Интерфейс обновлён в светлом стиле с локальным шрифтом Roboto. Принципы оформления описаны в [DESIGN.md](DESIGN.md).
- Публичный сервер, постоянный домен и реальный бот в Telegram пока не подключены и не проверены на устройстве пользователя. Локальный просмотр использует тестовый Telegram ID; он не заменяет проверку входа через Telegram.

## Следующие задачи

1. Заполнить упражнения, рабочие веса и расписание реальной программой.
2. Проверить полный сценарий с отдельным тестовым ботом: `/start`, открытие Mini App, получение уведомления, запись и завершение занятия на телефоне.
3. Перед публичным запуском настроить домен, HTTPS, переменные окружения, внешнее хранение резервных копий и миграции схемы БД.
4. При необходимости добавить принадлежность каждого упражнения к конкретной мышечной группе. Сейчас в смешанной тренировке весь объём занятия учитывается в сводке каждой выбранной группы; это объём **тренировок с группой**, а не изолированный объём этой мышцы.
5. При росте числа пользователей выделить отправку уведомлений в отдельный процесс с защитой от повторной отправки при сбоях.

## Запуск и безопасность

Для локального просмотра: `./scripts/local.ps1 preview`. Для проверки в Telegram используется отдельный тестовый бот и команда `./scripts/local.ps1 telegram`. Токены и пароли задаются только в локальных `.env`/`.env.local`, которые исключены из Git. Файлы `.env.example` и `.env.local.example` содержат шаблоны настроек. Инструкции по развёртыванию и правила расчёта находятся в [README.md](README.md).
